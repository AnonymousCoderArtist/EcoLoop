FAQ

Questions,
answered

What if waste is mixed — can it still scan?—

Yes. That's the point. Gemini 2.5 Flash detects stream-area zones (2-6), not per-object. A single photo with bottles + peels + masks → 3 zones. Biogas priority ensures organics aren't lost.

How are EcoPoints calculated?+

Deterministic demo: Biogas 15, Recyclable 10, Non-Recyclable 5, Others 0, E-Waste 25 per zone. Sum → total. Shown at GET /api/stats and awarded on POST /api/demo/analyze.

Is the annotated image real AI or mock?+

Real. Run uv run python backend/visualize.py → live Gemini → backend/image_annotated.png (Swiss light wash + 11px corners). Demo endpoint POST /api/demo/analyze replays it with 1.2s loader for judges.

What about privacy / camera?+

Camera is on-device only — image sent as multipart/form-data image to 127.0.0.1:5000 (CORS * for local). No DB, no auth in Round-1. Close → stream stops.

Can I run backend + frontend on different laptops?+

Yes. Backend uv run python backend/app.py (or HOST=0.0.0.0 in backend/.env) + frontend python -m http.server 8080 — fetch http://<backend-ip>:5000/api/analyze. See docs/API.md §7.
